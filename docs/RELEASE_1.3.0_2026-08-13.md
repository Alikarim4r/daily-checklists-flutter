# إصدار 1.3.0 (7) — 13 أغسطس 2026

## ما تم إنجازه

- جعل الصور والتوقيع أدلة غير قابلة للاستبدال، وربط اسم الملف ببصمة محتواه.
- منع حذف الأدلة من سجل قديم، مع حذف آمن ومصرّح به لمسودة كاملة فقط.
- استئناف تنظيف وسائط المسودة تلقائياً بعد انقطاع الشبكة.
- منع إنشاء PDF مرسل أو معتمد إذا تعذر تضمين التوقيع أو أي صورة مطلوبة.
- إصلاح مزامنة العمل دون اتصال والتحقق الفعلي من الوصول إلى الخادم.
- تخزين هيكل الجهات والمواقع محلياً بصورة مشفرة للعمل الميداني دون اتصال.
- تصحيح مؤشرات المتابعة التاريخية ونسبة الإجابات المثالية للفترة المختارة.
- منع مطالبة البصمة المتكررة بسبب إعادة بناء الواجهة أو تغيير حجم النافذة.
- تعطيل نسخ بيانات التطبيق الحساسة احتياطياً من Android.
- إنشاء هوية Android Release محفوظة خارج المستودع، وبناء APK/AAB موقعة.

## التحقق المنفذ

- تطبيق الهجرات `001`–`033` على PostgreSQL نظيف واختبار دورة العمل وRLS.
- تحليل Flutter بلا أخطاء للتطبيقات الثلاثة والحزمة المشتركة.
- نجاح جميع اختبارات Flutter، بما فيها حافة التوقيع والوضع الداكن والتقارير.
- بناء Web Production للتطبيقات الثلاثة مع `DEMO_LOGIN=false`.
- بناء Android 1.3.0 (7) والتأكد من أن الشهادة ليست Android Debug.
- نشر GitHub Pages والتحقق من ملفات APK المنشورة ببصمة SHA-256 مطابقة.
- بناء وتثبيت تطبيقات macOS 1.3.0 (7) محلياً بتوقيع Apple Development.

## متطلبات تشغيلية لا تُستبدل بالكود

- يجب أخذ نسخة احتياطية واختبار استعادة، ثم تطبيق الهجرة `033` على مشروع
  Supabase الحي من جلسة موثقة قبل اعتماد حذف المسودات في الإصدار الجديد.
- حزم macOS العامة تحتاج شهادة Developer ID وApple notarization؛ النسخة
  المثبتة محلياً ليست حزمة توزيع عامة.
- يجب حفظ نسخة مشفرة خارج الجهاز من مفتاح Android Release؛ فقدانه يمنع
  إصدار تحديثات موقعة بنفس الهوية.
