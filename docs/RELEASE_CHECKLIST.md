# قائمة اعتماد الإصدار النهائي

## 1. الكود والجودة

- [ ] `./scripts/check_quality.sh` ناجح بالكامل.
- [ ] GitHub Quality Gate أخضر على الفرع المرشح.
- [ ] لا توجد أسرار أو ملفات `key.properties` أو keystores ضمن Git.
- [ ] رقم `version`/build فريد قبل الرفع إلى المتجر.

## 2. قاعدة البيانات

- [ ] نسخة احتياطية حديثة واختبار استعادة موثق.
- [ ] `supabase migration list --linked` مطابق للمشروع المقصود.
- [ ] `supabase db push --linked --dry-run` يعرض الهجرات المتوقعة فقط.
- [ ] تطبيق الهجرات المتسلسلة حتى `031` بنجاح في staging، بما فيها الحماية والتدقيق والإصدارات والإجراءات التصحيحية والصلاحيات المؤقتة.
- [ ] `supabase db lint --linked --fail-on error` ناجح.
- [ ] UUID المالك موجود في `platform_owners` ولا توجد صلاحيات مباشرة عليها.

## 3. اختبار الأدوار

- [ ] Owner: إدارة المؤسسات والمديرين فقط ضمن القواعد المحمية.
- [ ] Org super admin: لا يتجاوز مؤسسته.
- [ ] Site admin: يدير المواقع المعينة ولا يضيف بنوداً خارج نطاقها.
- [ ] Technician: ينشئ/يحفظ/يرسل مسودة ولا يعتمد أو يحذف سجلاً.
- [ ] Viewer: يرى السجلات المعتمدة فقط.
- [ ] مستخدم pending/suspended: لا يدخل التطبيقات المحمية.

## 4. دورة الفحص

- [ ] إنشاء مسودة من الكتالوج الخادمي.
- [ ] حفظ إجابات وصور وتوقيع ثم إرسال واعتماد.
- [ ] رفض الإرسال الناقص من الخادم.
- [ ] ظهور تعارض واضح عند تعديل نسختين متزامنتين.
- [ ] العمل دون اتصال، إغلاق التطبيق، الاستعادة، ثم المزامنة مرة واحدة.
- [ ] استمرار المشكلة المفتوحة في قائمة اليوم التالي ولوحة التشغيل.
- [ ] PDF عربي وإنجليزي، طباعة، وشعارات التقرير صحيحة.

## 5. حزم التوزيع

- [ ] Android AAB/APK موقّع بمفتاح release وليس debug.
- [ ] حفظ ملفات `dist/symbols` مع الإصدار المطابق.
- [ ] iOS IPA موقّع ومتحقق في App Store Connect/TestFlight.
- [ ] macOS موقّع بـDeveloper ID، موثّق notarized، ومثبت على جهاز نظيف.
- [ ] Web مبني بـ`APP_ENV=production` و`DEMO_LOGIN=false` ويعمل عبر HTTPS.

## 6. التشغيل والمراقبة

- [ ] سياسة الخصوصية والدعم وروابط المتجر محدثة.
- [ ] مراقبة أخطاء العميل والخادم والتنبيه عليها مفعلة في بيئة الإنتاج.
- [ ] خطة rollback للتطبيق موثقة؛ تغييرات قاعدة البيانات يعالجها ترحيل أمامي جديد.
- [ ] تجربة smoke نهائية بحسابات غير إدارية قبل تعميم الإصدار.
